The Food Ordering Application is a web-based application developed using Python, Flask, HTML, CSS, JavaScript and MySQL. It allows users to browse food items, manage their cart and proceed through the checkout process.

Technologies Used
- Frontend: HTML, CSS, JavaScript, Bootstrap (if used)
- Backend: Python, Flask
- Database: MySQL
- Tools: VS Code, Git, GitHub
